# Calculadora de Partidas Rankeadas

Projeto desenvolvido em JavaScript com o objetivo de praticar conceitos fundamentais de programação, como variáveis, funções, operadores, estruturas condicionais, loops, arrays e objetos.

A aplicação calcula o saldo de vitórias e derrotas de jogadores e determina seu nível de ranking de acordo com a quantidade de vitórias.

**Tecnologias utilizadas:** JavaScript

**Conceitos praticados:**

* Variáveis e operadores
* Funções e parâmetros
* Estruturas condicionais (`if`, `else if`, `else`)
* Estrutura de repetição (`for`)
* Arrays e objetos
* Retorno de funções
* Manipulação de dados de jogadores
